## What This Does

### The 8 Check-in Types

Every goal gets classified automatically:

| Type | When | What ARYA asks |
|------|------|----------------|
| `just_created` | 1 day, 0% | "What's the first small step?" |
| `stalled_early` | 3-6 days, 0% | "Have you had a chance to start?" |
| `stalled_week` | 7-13 days, 0% | "A week ago you said... How's that going?" |
| `stalled_long` | 14+ days, 0% | "What's getting in the way?" |
| `abandoned` | 21+ days, 0% | "Is this still something you want?" |
| `near_deadline` | Due in 3 days | "Where are you with it?" |
| `overdue` | Past due | "What happened — want to revisit?" |
| `completed_recent` | Just done | "How does that feel?" |

---

### How ARYA Asks — The Rules

Built into the system prompt:

```
Ask it ONCE. Don't repeat.
If they haven't started → ask what got in the way.
If they forgot → offer to adjust the reminder.
Never judge. Always curious.
Feel like a friend noticing.
Not an app reporting.
```

---

### Goal Specificity Push

Detects vague goals automatically:

```
"get fit"     → vague → ARYA asks for specificity
"run 5km"     → specific → no push needed
"read more"   → vague
"1 book/month" → specific
```

Uses regex patterns — no extra API call needed.
