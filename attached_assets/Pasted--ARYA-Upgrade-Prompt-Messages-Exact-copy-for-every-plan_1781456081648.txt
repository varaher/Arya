# ARYA — Upgrade Prompt Messages
## Exact copy for every plan gate in the app

---

## The Design Principle

Every upgrade prompt follows the same structure:

```
1. Acknowledge what they just tried to do
2. Tell them what they need (plan name + price)
3. One line on why it's worth it
4. Two buttons: upgrade or continue on free
```

Never shame. Never alarm. Never pressure.
Just: here's what you tried, here's how to get it.

## Design Notes for Developer

```
All upgrade prompts:
→ Bottom sheet (slides up from bottom)
→ Dark background overlay
→ Two buttons always:
   Primary: upgrade (green, full width)
   Secondary: continue/dismiss (ghost button)
→ Never full-screen modal (too aggressive)
→ Dismissable with back swipe
→ Never shown more than once per session
   for the same trigger

Timing:
→ Show immediately when limit hit
→ Not on a delay — instant feedback

Tone:
→ Never: "You need to upgrade to access this"
→ Always: "This is available on Core — ₹249/month"
→ The difference is subtle but important.
   One sounds like a wall. One sounds like an option.
```

## Tracking — What To Log

```
For each upgrade prompt shown:
→ Log: prompt_type, user_id, plan_at_time, timestamp

For each upgrade prompt that converted:
→ Log: prompt_type, user_id, converted_to_plan, timestamp

This tells you:
Which features drive the most upgrades?
Which prompts convert best?
Where are users hitting walls most often?

Highest expected converters:
1. Document Intelligence (tasks → goals)
2. Voice input
3. Memory reset (frustrating to lose context)
4. Conversation limit
5. Weekly Review

Track this from day 1.
The data will tell you where to invest next.
```
