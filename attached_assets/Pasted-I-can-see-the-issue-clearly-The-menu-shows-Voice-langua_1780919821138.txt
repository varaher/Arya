## The Bug

When user taps "Voice language" — it should open a language selection list. Instead it's just displaying the current language without any picker.

**Two possible causes:**

### Cause A — Click handler not wired
```tsx
// In AryaChat.tsx — find the Voice language menu item
// It probably looks like this (broken):

<div className="menu-item">
  <Globe className="menu-icon" />
  <span>Voice language</span>
  <span className="current-lang">മലയാളം</span>
</div>

// Missing onClick — needs:
<div
  className="menu-item"
  onClick={() => {
    setShowDotMenu(false);    // close the dots menu
    setShowLangPicker(true);  // open language picker
  }}
>
```

### Cause B — Language picker state not toggling
```tsx
// Check if showLangPicker state exists and is connected
// to the language dropdown component
```

## The Fix — Exact Code

Find the `...` menu handler in AryaChat.tsx where "Voice language" is rendered:

```tsx
// 1. Add state if missing:
const [showLangPicker, setShowLangPicker] = useState(false);

// 2. Wire the menu item:
{/* Voice language menu item */}
<button
  className="dots-menu-item"
  onClick={() => {
    setShowDotsMenu(false);   // close dots menu
    setShowLangPicker(true);  // open language list
  }}
>
  <span className="dots-menu-icon">🌐</span>
  <div>
    <p className="dots-menu-label">Voice language</p>
  </div>
  <span className="dots-menu-current">
    {getLangNativeName(selectedLanguage)}
  </span>
</button>

// 3. Show language picker when open:
{showLangPicker && (
  <div
    className="lang-picker-overlay"
    onClick={() => setShowLangPicker(false)}
  >
    <div
      className="lang-picker-sheet"
      onClick={e => e.stopPropagation()}
    >
      <p className="lang-picker-title">Voice Language</p>

      {AVAILABLE_LANGUAGES.map(lang => (
        <button
          key={lang.code}
          className={`lang-option ${
            selectedLanguage === lang.code ? 'selected' : ''
          }`}
          onClick={() => {
            handleLanguageChange(lang.code); // your existing handler
            setShowLangPicker(false);
          }}
        >
          <span className="lang-native">{lang.native}</span>
          <span className="lang-english">{lang.name}</span>
          {INDIAN_LANG_CODES.includes(lang.code) && (
            <span className="lang-beta">BETA</span>
          )}
          {selectedLanguage === lang.code && (
            <span className="lang-check">✓</span>
          )}
        </button>
      ))}
    </div>
  </div>
)}
```
