### Fix For Notifications

```typescript
// In NotificationBell component
// Find the mark all read handler:

async function markAllRead() {
  await fetch('/api/user/notifications/read-all', {
    method: 'POST',
    headers: {
      'x-user-token': userToken,
      'Content-Type': 'application/json'
    }
  });

  // Force refresh notification count
  setUnreadCount(0);           // ← immediate UI update
  await refetchNotifications(); // ← sync with server
}

// Also: when panel opens → auto mark as read
useEffect(() => {
  if (isOpen && unreadCount > 0) {
    markAllRead();
  }
}, [isOpen]);
```
