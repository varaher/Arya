## How It Works — Auto Language Detection

```
User speaks in Malayalam
        ↓
Sarvam STT with language_code: "unknown"
        ↓
Sarvam detects: "ml-IN"
        ↓
ARYA generates response in Malayalam
        ↓
Sarvam TTS speaks back in Malayalam
        ↓
User speaks in Hindi next message
        ↓
Sarvam detects: "hi-IN"
        ↓
ARYA responds in Hindi automatically
```

No globe selection needed for voice. It just works.

## The Complete Auto-Detection Flow

```typescript
// server/routes.ts — complete voice handler

// Step 1: Transcribe with auto-detection
const sttResult = await sarvamSpeechToText(
  audioBuffer,
  "unknown"        // auto-detect
);

const detectedLang = sttResult.languageCode; // "ml-IN"
const transcript = sttResult.transcript;      // Malayalam text

console.log(`[voice] ${detectedLang}: "${transcript}"`);

// Step 2: If Indian language → ARYA responds directly
// No translation needed — generate in detected language
const langInstruction = getLanguageInstruction(
  detectedLang, userName
);

// Step 3: Generate ARYA response in detected language
const { stream } = await generateAryaResponse(
  transcript,
  history,
  tenantId,
  conversationId,
  userId,
  langInstruction   // ← ARYA responds in Malayalam
);

// Step 4: TTS in detected language
const ttsResult = await sarvamTextToSpeech(
  aryaResponse,
  detectedLang as SarvamLanguageCode  // "ml-IN"
  // speaker resolved internally: ananya
);
```

## One Important Thing

```
Sarvam "unknown" detection works well for:
  ✅ Hindi, Tamil, Telugu, Kannada
  ✅ Malayalam, Bengali, Marathi
  ✅ Gujarati, Punjabi, Odia
  ✅ English

It may struggle with:
  ⚠ Very short audio (less than 2 seconds)
  ⚠ Heavy background noise
  ⚠ Mixed language in same sentence

Fallback for failed detection:
  If languageCode comes back "unknown"
  or detection fails → use "en-IN" as default
  OR use user's last known language preference
```

// If Sarvam can't detect:
const detectedLang = sttResult.languageCode;

const finalLang = (
  detectedLang &&
  detectedLang !== "unknown" &&
  detectedLang !== ""

  ? detectedLang
  : (user?.uiLanguage || "en-IN");
  // fall back to user's app language setting
