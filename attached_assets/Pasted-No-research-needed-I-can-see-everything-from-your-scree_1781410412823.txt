## But It's Still Not Working

The bug fix was correct — renaming `window` to `win` so `window.dispatchEvent()` works. But there's likely a second issue.

The button fires a **custom browser event**. The chat needs to be **listening for that event**. If the listener isn't set up, the event fires into nothing.

---

## Check These Two Things

### Thing 1 — Is the event listener in AryaChat.tsx?

```typescript
// This MUST exist in AryaChat.tsx:

useEffect(() => {
  function handleKaalMessage(e: CustomEvent) {
    const message = e.detail?.message;
    if (message) {
      setInput(message);
      // Also need to navigate to Home tab:
      setActiveTab('home'); // or however home is activated
      setTimeout(() => inputRef.current?.focus(), 400);

  }

  window.addEventListener('arya-kaal-ask', handleKaalMessage);
  return () => {
    window.removeEventListener('arya-kaal-ask', handleKaalMessage);
```

If this listener doesn't exist — the event fires but nobody receives it.
