## Small Observations

### 1. Core Plan — Missing Feature List (Image 3)
Core card shows price + subscribe button but **no feature bullets visible.** Pro and Elite have them. Core needs them too. Users won't subscribe to a plan they can't see the value of.

### 2. "International checkout coming soon" (Image 10)
Good — honest. But the button should be **disabled/greyed out** not active. Users may tap it expecting to pay.

```tsx
// Change from:
<button>Subscribe — $7.99</button>
<p>International checkout coming soon</p>

// To:
<button disabled className="coming-soon-btn">
  Coming soon — $7.99
</button>
```

### 3. Core vs Pro Voice Minutes — Check This

Image 5 shows:
- Core: **150 min/month**
- Pro: **50 min/month + overages**

This seems backwards. Core users get MORE voice than Pro? That's confusing. Likely a display error in the comparison table.

Should probably be:
```
Free:  No voice
Core:  150 min/month
Pro:   50 min + ₹2/min after (capped ₹200)
Elite: Unlimited
```

Or flip it — Pro should have more voice than Core.

### 4. Annual Pricing — Not Shown

Toggle exists (Image 2, 11) but annual prices aren't visible in screenshots. When user toggles to Annual, prices should update:

```
Core:  ₹249 → ₹207/mo (₹2,490/year = 2 months free)
Pro:   ₹499 → ₹416/mo (₹4,990/year)
Elite: ₹999 → ₹833/mo (₹9,990/year)
```
