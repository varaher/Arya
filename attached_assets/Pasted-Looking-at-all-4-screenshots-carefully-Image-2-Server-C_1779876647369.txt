## What The 400 Error Means

```
Sarvam TTS failed (400) = Bad Request

400 means Sarvam is rejecting the request.
Most common causes:

1. Text too long (over 500 chars)
   The .slice(0, 500) fix may not have deployed

2. Wrong language code format
   Sending "ml" instead of "ml-IN"

3. Invalid speaker name
   "ananya" not valid for this language

4. Special characters in text
   Malayalam Unicode causing issues
```
