It says: *"Patient has SDH SCH and patient is waiting for MICU"*

But written in Malayalam script phonetically — which means Sarvam received it as audio and transcribed English speech into Malayalam script characters.

```
What was said (English):    "Patient has SDH and SCH..."
What Sarvam returned:       "പേഷ്യന്റ് ഹാസ് ആൻഡ്..."
                             (English sounds in Malayalam letters)
What should happen:         Detect language → if English → use 
                            English transcription
```

```typescript
// After getting transcript from Sarvam:
function isTransliterated(text: string): boolean {
  // Check if Malayalam unicode but contains English phonetics
  const malayalamChars = (text.match(/[\u0D00-\u0D7F]/g) || []).length;
  const totalChars = text.replace(/\s/g, '').length;
  const malayalamRatio = malayalamChars / totalChars;

  // Common transliterated patterns
  const englishPatterns = /ഹാസ്|ആൻഡ്|ഈസ്|ഫോർ|വിത്ത്|ദി|ദാറ്റ്/;

  return malayalamRatio > 0.5 && englishPatterns.test(text);
}

// If transliterated → re-transcribe with Whisper
```
