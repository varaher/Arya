## Wiring — Tell Your Developer

```
□ 1. Save card-generator.ts to:
      server/arya/card-generator.ts

□ 2. Add route to routes.ts:
      GET /api/cards/:type/:userId
      → Returns SVG image

□ 3. Add to Replit secrets:
      APP_URL = https://aryaai.in

□ 4. Update reminder-scheduler.ts:
      Morning briefing notification:
        image: APP_URL/api/cards/morning/userId
      
      Goal check-in notification:
        image: APP_URL/api/cards/goal_checkin/userId
      
      Story offer notification:
        image: APP_URL/api/cards/story/userId

□ 5. Update sw.js — add handlers:
      open_arya → clients.openWindow('/')
      voice_chat → clients.openWindow('/?voice=true')
      listen → clients.openWindow('/?tab=drishya&autoplay=true')

Total: 2-3 hours
```
