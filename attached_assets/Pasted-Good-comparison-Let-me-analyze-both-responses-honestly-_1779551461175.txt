## Why This Happens

ARYA's system prompt currently prioritizes:
```
✓ Warm friend tone
✓ Short responses
✓ Conversational style
✗ But sacrifices: data, structure, specifics
```

ChatGPT's default prioritizes:
```
✓ Structured information
✓ Specific numbers
✓ Research-backed claims
✓ Scannable formatting
```

## The Fix — ARYA Should Do Both

ARYA can be warm AND informative. The system prompt needs one addition:

```typescript
// server/arya/chat-engine.ts
// Add to system prompt:

`When answering health, fitness, science,
or factual questions:
- Include specific numbers and data
- Use bullet points for lists
- Bold key facts
- Cite "research shows" where relevant
- Then add the personal warm touch

Example for walking question:
"Research shows 7,000–8,000 steps/day
gives major heart and longevity benefits.
You don't need 10,000 — that number was
actually from a 1960s Japanese marketing
campaign, not science.

What matters more:
• Consistency over perfection
• Even 4,000 steps beats being sedentary
• Your lifestyle and health goals matter more
  than hitting an exact number

What's your current activity like?
I can help you set a realistic goal."

This is warm AND data-rich.`
```
