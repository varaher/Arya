## The Core Problem

```
Desktop → everything visible ✅
Mobile → nothing visible / not scrolling ❌

This is a responsive design issue.
The layout works for wide screens
but breaks on narrow phone screens.
```

---

## Why This Happens

```
Desktop screen width: ~1200px
Mobile screen width: ~390px

Elements designed for desktop:
  Quick chips row → 8 chips in one row
  On mobile: overflow hidden, chips disappear

Scroll not working on mobile:
  overflow: hidden somewhere blocking scroll
  OR touch events not registered
  OR content height not set correctly
```

---

## Tell Your Developer — Mobile Fix

### Fix 1 — Quick Chips Row
```
File: AryaChat.tsx or HomeScreen
Find: The chips row (Goals Memory Notes Mood...)

Current (broken on mobile):
  display: flex
  flex-wrap: nowrap  ← forces one line
  overflow: hidden   ← hides overflow

Fix:
  display: flex
  flex-wrap: nowrap
  overflow-x: auto           ← scroll horizontally
  -webkit-overflow-scrolling: touch
  scrollbar-width: none      ← hide scrollbar
  padding-bottom: 4px        ← prevent cutoff

On mobile: swipe left/right to see all chips
On desktop: all visible in one row
```

### Fix 2 — Mobile Scroll Not Working
```
The universal scroll fix was applied
but something is still blocking mobile.

Check these in order:

1. Is there overflow: hidden on
   the main app container?
   
   Find in App.tsx or index.css:
   .app-container or #root or body
   Change overflow: hidden → overflow-y: auto

2. Is the page height fixed?
   height: 100vh with overflow: hidden
   Change to: min-height: 100vh

3. Touch events on iOS:
   Add to main container:
   -webkit-overflow-scrolling: touch
   touch-action: pan-y

4. Check on Android Chrome AND iPhone Safari
   They behave differently
```

### Fix 3 — Community Page On Mobile
```
Image 2 shows beautiful desktop design
But not visible on mobile.

The community page likely has:
  Fixed width elements
  No mobile responsive CSS

Quick check:
  Add to community page container:
  width: 100%
  max-width: 100vw
  overflow-x: hidden
  padding: 16px
```

## The Root Cause — Likely One File

```
Most likely the main app wrapper
in App.tsx or index.css has:

.app {
  height: 100vh;
  overflow: hidden;   ← THIS IS BLOCKING SCROLL
}

Change to:
.app {
  min-height: 100vh;
  overflow-y: auto;
  -webkit-overflow-scrolling: touch;
}

This one change likely fixes:
  Mobile scroll ✅
  Chips row accessible ✅
  Community page visible ✅
  All pages scrollable ✅
```
