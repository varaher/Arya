### What Needs Care For Teens ⚠️
```
Medical document analysis:
  Teen uploads a medical report
  ARYA gives detailed clinical analysis
  
  For a professional (you) → perfect ✅
  For a teenager → could be:
    Scary if they misinterpret results
    Anxiety-inducing without context
    Should always say "discuss with doctor"

Legal document analysis:
  Teen uploads legal notice
  Without adult guidance → risky
  Should always say "discuss with parent/lawyer"

Mental health conversations:
  Teens are vulnerable
  ARYA needs extra care
  Always suggest trusted adult/professional
```

## The Table Rendering Fix

```
Tell developer:

File: client/src/components/FormattedMessage.tsx
OR wherever markdown is rendered

Tables with | pipes | are not rendering
as visual HTML tables.

Add to the ReactMarkdown components:

import remarkGfm from 'remark-gfm'

<ReactMarkdown
  remarkPlugins={[remarkGfm]}  ← ADD THIS
  components={{
    table: ({children}) => (
      <div className="table-wrapper">
        <table className="arya-table">
          {children}
        </table>
      </div>
    ),
    th: ({children}) => (
      <th className="arya-th">{children}</th>
    ),
    td: ({children}) => (
      <td className="arya-td">{children}</td>
    ),
  }}
>
  {content}
</ReactMarkdown>

CSS:
.arya-table {
  width: 100%;
  border-collapse: collapse;
  font-size: 13px;
  margin: 12px 0;
  overflow-x: auto;
  display: block;
}

.arya-th {
  background: #f0f4f0;
  border: 1px solid #ddd;
  padding: 8px;
  text-align: left;
  font-weight: 600;
  white-space: nowrap;
}

.arya-td {
  border: 1px solid #ddd;
  padding: 8px;
  vertical-align: top;
}

.table-wrapper {
  overflow-x: auto;
  -webkit-overflow-scrolling: touch;
  margin: 8px 0;
}
```

## Add Teen Safety To System Prompt

```typescript
// server/arya/chat-engine.ts
// Add to system prompt:

`TEEN AND YOUNG USER SAFETY:
When user appears to be a student or teen:

Medical results or reports:
  Always end with:
  "These results should be discussed with
   your doctor who knows your full history.
   Don't worry based on reports alone."

Legal documents:
  Always end with:
  "Share this with a parent or trusted adult.
   A lawyer can explain what this means
   for your specific situation."

Mental health topics:
  Extra warmth and care.
  Always mention a trusted adult or
  school counselor as a resource.
  Never dismiss feelings.
  Never minimize what they're going through.

Academic pressure:
  Validate the stress.
  Give practical help.
  Remind them their worth is not their grades.

Career confusion:
  Explore options without pressure.
  "There's no single right path."
  Indian context — family expectations
  are real, acknowledge them.`
```
