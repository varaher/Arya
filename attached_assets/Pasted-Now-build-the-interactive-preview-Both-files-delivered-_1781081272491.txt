## What Was Built — 6 Parts

### Part 1 — Study Intent Detector
Automatically detects when user wants to study:

```
"Help me study photosynthesis" → exam_prep
"Make a PPT on water cycle"    → ppt_prep
"Explain cell division"        → concept_learn
"Essay on climate change"      → essay_writing
"Key points of chapter 5"      → topic_summary
```

No user needs to select a mode. ARYA notices.

### Part 2 — Notes Content Parser
Extracts hidden `[NOTES_CONTENT]` blocks from ARYA's response:

```
Bullets → key points
Terms   → definitions
Q:      → exam questions
PPT     → slide outline
```

Block is invisible to user. Extracted silently. Saved automatically.

### Part 3 — Study Note Toast

```
📚 Saved to Notes
   Photosynthesis — Class 10 Exam Prep
   [Open →]
```
Slides up from bottom. Auto-dismisses in 6 seconds. Uses `createPortal` — no positioning bugs.

### Part 4 — Study Note Card
Different from voice note card:

```
📚 Photosynthesis — Exam Prep  [From chat]

✨ SUMMARY
• 6CO₂ + 6H₂O → glucose + oxygen
• Happens in chloroplast
• Chlorophyll captures sunlight

❓ LIKELY EXAM QUESTIONS
1. What are the raw materials?
2. Where does it happen?
3. Why are leaves green?

[📋 Copy]  [📖 Open chat]
```

PPT requests also get a slide-by-slide outline in the note card.
