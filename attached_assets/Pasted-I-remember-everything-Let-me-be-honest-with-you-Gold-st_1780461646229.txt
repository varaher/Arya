### Reform 4 — Decision Record

At session end (when user closes or after 30 min inactivity), ARYA auto-generates:

```typescript
// server/routes.ts — POST /api/niti/sessions/:id/record
async function generateDecisionRecord(sessionId: number) {
  const messages = await getSessionMessages(sessionId);
  
  const record = await openai.chat.completions.create({
    model: 'gpt-4o',
    messages: [{
      role: 'system',
      content: `You are closing a Niti thinking session.
      Write a Decision Record in this exact format:
      
      WHAT YOU WERE WRESTLING WITH:
      [1-2 sentences — the real question, not the surface one]
      
      WHAT EMERGED:
      [What shifted during the thinking. The insight.]
      
      THE QUESTION THAT MATTERED:
      [The single push question that changed something]
      
      WHAT YOU MIGHT DECIDE:
      [Leave this open — user fills it]
      
      REVISIT IN:
      [7 / 14 / 30 days — based on urgency]
      
      Be honest. Be brief. No padding.
      Write like someone who was in the room.`
    }, {
      role: 'user',
      content: `Session transcript:\n${messages
        .map(m => `${m.role}: ${m.content}`)
        .join('\n')}`
    }],
    max_tokens: 300
  });

  // Save to session
  await db.update(arya_niti_sessions)
    .set({ 
      decisionRecord: record.choices[0].message.content,
      closedAt: new Date()
    })
    .where(eq(arya_niti_sessions.id, sessionId));
}
```
