## Complete Chat Screen Structure

```tsx
// Clean Claude-style chat layout

<div className="chat-screen">

  {/* Messages area */}
  <div className="messages-container">
    {messages.map(msg => (

      msg.role === 'user' ? (
        // User message — right aligned bubble
        <div className="message-row user">
          <div className="user-message">
            {msg.content}
          </div>
        </div>
      ) : (
        // ARYA response — open, full width
        <div className="message-row arya">
          <div className="arya-label">ARYA</div>
          <div className="arya-message">
            <FormattedMessage content={msg.content} />
          </div>
          <div className="message-actions">
            <button className="action-btn">
              📋 Copy
            </button>
            <button className="action-btn">
              👍
            </button>
            <button className="action-btn">
              👎
            </button>
          </div>
        </div>
      )

    ))}
  </div>

  {/* Input bar */}
  <div className="chat-input-bar">
    <button className="mic-btn">🎙️</button>
    <textarea
      className="chat-textarea"
      placeholder="Ask ARYA anything..."
    />
    <button className="send-button">→</button>
  </div>

</div>
```
