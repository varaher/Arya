## The Extraction Logic

Add to `document-processor.ts`:

```typescript
export interface DocumentExtracts {
  summary: string[];           // Key bullet points
  tasks: string[];             // Action items found
  dates: ExtractedDate[];      // Dates + times found
  examQuestions: string[];     // For study content
  terms: string[];             // Definitions found
}

export interface ExtractedDate {
  text: string;          // "NABH audit"
  dateString: string;    // "June 28, 10 AM"
  isoDate?: string;      // "2026-06-28T10:00:00"
}

// GPT-4o mini extraction prompt:
export const DOCUMENT_EXTRACTION_PROMPT = `
Analyse this document and extract:

1. SUMMARY: 4-6 bullet points covering the main content
   Format: bullet per line starting with •

2. TASKS: Any action items, to-dos, things that need doing
   Look for: "complete", "submit", "prepare", "attend",
   "review", "finish", "send", "call", "schedule"
   Format: one task per line starting with TASK:

3. DATES: Any dates, deadlines, schedules mentioned
   Format: DATE: [what it is] | [date and time as mentioned]

4. EXAM_QUESTIONS: If study/educational content —
   generate 3-5 likely exam questions from this content
   Format: Q: [question]

5. TERMS: Important terms or definitions found
   Format: TERM: [term] — [definition]

Be specific. Don't invent what isn't there.
If a category has nothing — leave it empty.

Document content:
{document_text}
`;
```
