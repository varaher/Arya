This is a known issue with file downloads in PWA/mobile browsers. Let me diagnose.

---

## Why Download Fails On Mobile

```
ARYA generates the .docx file
Provides a download link
User taps the link on Android
Nothing downloads OR
Browser opens a blank page ❌

Three possible causes:
1. Link expires quickly (temp file)
2. Mobile browser blocks .docx download
3. File served without correct headers
4. PWA intercepts the download request
```

---

## The Fix — Three Approaches

### Approach 1 — Direct Download Button (Best)
```typescript
// Instead of a link, show a button
// that triggers download immediately

// In AryaChat.tsx — when ARYA generates
// a downloadable file:

<button
  onClick={async () => {
    const response = await fetch(fileUrl);
    const blob = await response.blob();
    const url = URL.createObjectURL(blob);
    const a = document.createElement('a');
    a.href = url;
    a.download = 'NABH_ED_Indicators.docx';
    document.body.appendChild(a);
    a.click();
    document.body.removeChild(a);
    URL.revokeObjectURL(url);
  }}
  className="download-btn"
>
  ⬇️ Download NABH Template
</button>
```

### Approach 2 — Open In New Tab
```typescript
// Force open in browser tab
// User can then use browser's
// own download mechanism

<a
  href={fileUrl}
  target="_blank"
  rel="noopener noreferrer"
  download="NABH_ED_Indicators.docx"
>
  ⬇️ Download NABH Template
</a>
```

### Approach 3 — Share Via WhatsApp
```typescript
// For mobile users — share file
// directly via WhatsApp or Files app

if (navigator.share) {
  await navigator.share({
    title: 'NABH ED Indicators Template',
    files: [docxFile]
  });
}
```

```
  Also add "Share" button:
  Uses native Web Share API
  User can share to WhatsApp/Files
  Works on all mobile browsers

Fix 3 — File headers (15 mins):
  In server/routes.ts file download route:
  Add correct Content-Type header:
  
  res.setHeader('Content-Type',
    'application/vnd.openxmlformats-officedocument
     .wordprocessingml.document');
  res.setHeader('Content-Disposition',
    'attachment; filename="NABH_Template.docx"');
  
  This tells browser to download
  not open or block the file.
```
