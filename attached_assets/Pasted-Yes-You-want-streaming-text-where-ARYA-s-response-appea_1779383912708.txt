Yes. You want **streaming text** — where ARYA's response appears word by word as it's generated, exactly like Claude does.

---

## Why It Currently Shows All At Once

Right now the flow is:

```
User sends message
        ↓
Server calls Claude API
        ↓
Waits for COMPLETE response
        ↓
Sends everything at once to frontend
        ↓
Frontend displays full text instantly
```

What you want:

```
User sends message
        ↓
Server calls Claude API with streaming ON
        ↓
Each word/chunk arrives → sent to frontend immediately
        ↓
Frontend displays each chunk as it arrives
        ↓
User sees text appearing word by word
```

---

## The Fix — Two Parts

### Part 1 — Server: Enable Streaming

```typescript
// server/arya/chat-engine.ts
// Find where Claude API is called
// Change from regular call to streaming

// BEFORE — waits for complete response
const response = await openai.chat.completions.create({
  model: 'gpt-4o',
  messages: messages,
  // No stream — waits for everything
});

const content = response.choices[0].message.content;
return content;


// AFTER — streams word by word
async function* generateStreamingResponse(
  messages: any[],
  res: Response  // Express response object
) {
  // Set headers for SSE (Server-Sent Events)
  res.setHeader('Content-Type', 'text/event-stream');
  res.setHeader('Cache-Control', 'no-cache');
  res.setHeader('Connection', 'keep-alive');
  res.setHeader('X-Accel-Buffering', 'no'); // Important for Replit

  try {
    const stream = await openai.chat.completions.create({
      model: 'gpt-4o',
      messages: messages,
      stream: true,  // ← THIS is the key change
    });

    for await (const chunk of stream) {
      const text = chunk.choices[0]?.delta?.content || '';

      if (text) {
        // Send each chunk to frontend immediately
        res.write(`data: ${JSON.stringify({ text })}\n\n`);
      }
    }

    // Signal stream is complete
    res.write(`data: ${JSON.stringify({ done: true })}\n\n`);
    res.end();

  } catch (error) {
    res.write(`data: ${JSON.stringify({ error: 'Stream failed' })}\n\n`);
    res.end();
  }
}
```

### Part 2 — Frontend: Read The Stream

```typescript
// client/src/hooks/useARYAChat.ts

async function sendMessage(userMessage: string) {
  // Add user message to UI immediately
  setMessages(prev => [...prev, {
    role: 'user',
    content: userMessage
  }]);

  // Add empty ARYA message — will fill in as stream arrives
  const aryaMsgId = Date.now().toString();
  setMessages(prev => [...prev, {
    id: aryaMsgId,
    role: 'arya',
    content: '',        // starts empty
    isStreaming: true   // shows cursor
  }]);

  try {
    const response = await fetch('/api/arya/chat', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        message: userMessage,
        conversationId,
        language: selectedLanguage,
        section: 'chat'
      })
    });

    // Read the stream
    const reader = response.body!.getReader();
    const decoder = new TextDecoder();
    let accumulated = '';

    while (true) {
      const { done, value } = await reader.read();
      if (done) break;

      const chunk = decoder.decode(value);
      const lines = chunk.split('\n');

      for (const line of lines) {
        if (!line.startsWith('data: ')) continue;

        try {
          const data = JSON.parse(line.slice(6));

          if (data.done) {
            // Stream finished — mark as complete
            setMessages(prev => prev.map(msg =>
              msg.id === aryaMsgId
                ? { ...msg, isStreaming: false }
                : msg
            ));
            break;
          }

          if (data.text) {
            accumulated += data.text;

            // Update the ARYA message with new text
            setMessages(prev => prev.map(msg =>
              msg.id === aryaMsgId
                ? { ...msg, content: accumulated }
                : msg
            ));
          }

        } catch {
          // Skip malformed chunks
        }
      }
    }

  } catch (error) {
    console.error('[chat] Stream error:', error);
    setMessages(prev => prev.map(msg =>
      msg.id === aryaMsgId
        ? { ...msg,
            content: 'Something went wrong. Please try again.',
            isStreaming: false }
        : msg
    ));
  }
}
```

## Important — Sarvam Translation With Streaming

Currently for Indian languages the flow is:

```
Claude generates English → Sarvam translates → show result
```

With streaming this needs adjustment:

```
Option A — Stream English, translate at end
  Show English streaming (user sees it building)
  When complete → replace with Sarvam translation
  Slight jarring effect

Option B — Stream Claude English invisibly
  Show "ARYA is thinking..." while streaming
  When complete → Sarvam translates → show result
  No streaming feel but clean language

Option C — Best: Direct Hindi/Tamil streaming
  Instead of translate-after approach
  Tell Claude to respond directly in Hindi/Tamil
  Stream that directly — no translation step
  Fastest, cleanest, most natural
```

**Option C is the right answer** — and it's already partly set up with your language instruction in the system prompt. Claude can generate Hindi/Tamil directly and stream it. Remove the Sarvam translate step for text chat (keep Sarvam only for TTS voice output).
