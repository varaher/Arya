## The Universal Scroll Fix

```css
/* Global CSS — add to index.css */

/* Every page scrolls if content overflows */
html, body {
  height: 100%;
  overflow-y: auto;
}

/* Hide scrollbar visually but keep scroll */
* {
  scrollbar-width: none;        /* Firefox */
  -ms-overflow-style: none;     /* IE/Edge */
}

*::-webkit-scrollbar {
  display: none;                /* Chrome/Safari */
}

/* All page containers scroll naturally */
.page-container {
  min-height: 100vh;
  overflow-y: auto;
  -webkit-overflow-scrolling: touch; /* iOS smooth */
}
```
