## Fix 2 — Voice Notes AI Summary Missing

From your screenshot (Image 10), the voice note shows raw Malayalam transcription but **no English summary below it.**

**The problem is in your voice note save flow.** After Sarvam transcribes, you need to call Claude/GPT to summarize.

### Step 1 — Server side (`routes.ts`)

Find your voice note POST route and add summarization:

```typescript
// routes.ts — after Sarvam transcription succeeds
app.post('/api/voice-notes', async (req, res) => {
  const { audioData, language } = req.body;
  
  // Step 1: Transcribe with Sarvam (already working)
  const transcription = await sarvamService.transcribe(audioData, language);
  
  // Step 2: Summarize with GPT (ADD THIS)
  const summaryResponse = await openai.chat.completions.create({
    model: 'gpt-4o',
    messages: [
      {
        role: 'system',
        content: `You are ARYA. Summarize this voice note in 1-2 clear English sentences. 
                  Extract the key point or action item. Be concise.
                  If it's in another language, still summarize in English.`
      },
      {
        role: 'user', 
        content: transcription
      }
    ],
    max_tokens: 100
  });
  
  const summary = summaryResponse.choices[0].message.content;
  
  // Step 3: Save both to DB
  const note = await db.insert(voiceNotes).values({
    userId: req.user.id,
    transcription,
    summary,          // ADD this column if not exists
    language,
    duration: req.body.duration,
    createdAt: new Date()
  }).returning();
  
  res.json(note[0]);
});
```

### Step 2 — Database migration

Add `summary` column if not already there:
```sql
ALTER TABLE voice_notes ADD COLUMN IF NOT EXISTS summary TEXT;
```

Or in Drizzle schema:
```typescript
// shared/schema.ts — in voiceNotes table
summary: text('summary'),
```

In your Voice Notes panel component:
