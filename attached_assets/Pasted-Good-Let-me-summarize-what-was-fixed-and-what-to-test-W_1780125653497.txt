
### Fix 2 — Feedback Buttons Hidden
```

After:

```

### Fix 3 — Render Batching
```
Before:
  100 chunks per second streaming
  100 DOM updates per second
  Browser struggles to keep up
  Phone gets warm, battery drains

After:
  requestAnimationFrame batching
  Chunks grouped per frame (60fps)
  ~60 DOM updates per second max
  Smooth on phone, less battery ✅
```
