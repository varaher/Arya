## The One Fix — Multiple Choice for Goals

You're right. Health goals aren't exclusive. Someone wants **better sleep AND manage stress AND track vitals** simultaneously.

Single select was wrong. Here's the fix:

```tsx
// Change from single select to multi-select
const [selectedGoals, setSelectedGoals] = useState<string[]>([]);

function toggleGoal(value: string) {
  setSelectedGoals(prev =>
    prev.includes(value)
      ? prev.filter(g => g !== value)  // deselect
      : [...prev, value]               // select
  );
}

// Validation — at least one selected
const valid = selectedGoals.length > 0;
```

```tsx
// Each goal card
<button
  className={`goal-card ${selectedGoals.includes(opt.value) ? "selected" : ""}`}
  onClick={() => toggleGoal(opt.value)}
>
  {/* Add checkmark when selected */}
  {selectedGoals.includes(opt.value) && (
    <span className="goal-check">✓</span>
  )}
  <span className="goal-icon">{opt.icon}</span>
  <span className="goal-label">{opt.label}</span>
</button>
```

```tsx
// Subtitle changes to reflect multiple choice
<p className="step-subtitle">
  Pick all that apply.<br />
  <span style={{fontSize:'12px', opacity:0.4}}>
    {selectedGoals.length > 0
      ? `${selectedGoals.length} selected`
      : 'Be honest with yourself.'}
  </span>
</p>
```
