```
Bug: "Ask ARYA about today" button
     in VedicLensPage is not working

Root cause (likely one of these):
1. onClick calls setInput() but
   doesn't navigate to home tab
2. The navigation happens but
   KAAL panel stays open on top

Fix:
In VedicLensPage.tsx — handleAskARYA():

function handleAskARYA(message: string) {
  // Step 1: Set the chat input
  setInput(message);

  // Step 2: Close KAAL / switch to Home tab
  setActiveTab('home');
  // OR: navigate('/');
  // OR: onClose(); (if it's a panel)

  // Step 3: Focus the input
  setTimeout(() => {
    inputRef.current?.focus();
  }, 400); // wait for tab animation
}

The likely bug is Step 2 is missing —
input is set but KAAL never closes.
```
