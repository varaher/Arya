## Root Cause — All Three Same Problem

```
ALL errors point to Sarvam API.

Sarvam is returning 400 Bad Request for:
  TTS (text to speech) ❌
  Translation ❌

400 means the REQUEST FORMAT is wrong.
Not an API key issue (that would be 401).
Not rate limit (that would be 429).

The request body being sent to Sarvam
has something wrong in it.
```

## The Exact Fix

The log shows:
```
[Sarvam TTS] lang=ml-IN speaker=ananya
```

The issue is almost certainly the **text being sent is too long** OR contains **special characters** that Sarvam rejects.

Tell your developer:

```
In server/arya/sarvam-service.ts
Find sarvamTextToSpeech function

Add this before the API call:

// Log exactly what's being sent
console.log('[Sarvam TTS] text length:', text.length);
console.log('[Sarvam TTS] first 100 chars:', text.substring(0, 100));
console.log('[Sarvam TTS] full error body:', errorText);

// Clean the text before sending:
const cleanText = text
  .replace(/[^\u0000-\uFFFF]/g, '')  // remove emoji
  .replace(/\*\*/g, '')               // remove markdown bold
  .replace(/\*/g, '')                 // remove markdown italic
  .replace(/#{1,6}\s/g, '')           // remove headers
  .replace(/\n{3,}/g, '\n\n')         // limit newlines
  .trim()
  .slice(0, 500);                     // max 500 chars

// Use cleanText instead of text in API call
```
