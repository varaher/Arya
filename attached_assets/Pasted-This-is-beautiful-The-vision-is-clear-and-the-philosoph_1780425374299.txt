## Step 2 — The Proactive Trigger

In `server/arya/chat-engine.ts`, after generating each response, check if a story moment was missed:

```typescript
// After main response is generated
// Add this check to the system prompt context:

const storyContextCheck = `
After your response, if ANY of these are true:
1. User expressed strong emotion
2. User mentioned loss, failure, fear, grief
3. User achieved something
4. This feels like a moment that needs a story

END your response with exactly one line:
[STORY_MOMENT: {rasa}]

Example: [STORY_MOMENT: Karuna]

The app will use this to offer voice narration.
If no story moment, add nothing.
`;
```

Then in your response parser:

```typescript
// routes.ts or chat-engine.ts
function parseStoryMoment(response: string): {
  cleanResponse: string;
  storyMoment: string | null;
} {
  const match = response.match(/\[STORY_MOMENT:\s*(\w+)\]/);
  return {
    cleanResponse: response.replace(/\[STORY_MOMENT:[^\]]+\]/, '').trim(),
    storyMoment: match ? match[1] : null
  };
}
```

```typescript
// Language-aware offer text
function getStoryOfferText(lang: string): string {
  const offers: Record<string, string> = {
    'ml': 'ഒരു കഥ പറയട്ടെ?',

  };
  return offers[lang] || offers['en'];
}
```

## Step 4 — Story Generation + Voice

When user taps yes:

```typescript
// Story generation prompt
async function generateDrishyaStory(
  rasa: string,
  userContext: string,
  language: string
): Promise<string> {
  
  const response = await openai.chat.completions.create({
    model: 'gpt-4o',
    messages: [
      {
        role: 'system',
        content: `You are ARYA's storytelling voice — Drishya.
        
Tell a story that carries the rasa: ${rasa}.
The story should feel personal to: ${userContext}

Rules:
- 250-350 words maximum
- Tell in ${language}
- Draw from Indian tradition — Jataka, Panchatantra, 
  Mahabharata, Upanishads, regional folk tales
- Never name the source
- No moral stated at the end
- End with an image, not a lesson
- The reader should sit in silence after`
      },
      {
        role: 'user',
        content: `Tell me a story.`
      }
    ],
    max_tokens: 500,
    temperature: 0.85  // slightly creative
  });

  return response.choices[0].message.content || '';
}
```

Then immediately pass to Sarvam for voice narration:

```typescript
// After story text generated — speak it
```
