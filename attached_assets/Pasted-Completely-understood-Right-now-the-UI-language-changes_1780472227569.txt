## The Implementation Strategy

Tell your developer to do this in order:

**Day 1 — Audit:**
```bash
# Find every hardcoded string in TSX files
grep -rn '"[A-Z][a-z]' client/src/pages/ --include="*.tsx" \
  | grep -v "t(" | grep -v "className" | grep -v "//"`
```

This gives a list of every hardcoded English string that needs a translation key.

**Day 2 — Add keys to i18n.ts:**
Add all keys above to English section first. App still works — just now using `t("key")` instead of hardcoded strings.

**Day 3 — Replace in components:**
Go file by file. Replace every hardcoded string:
```tsx
// Before:
<p>No active reminders.</p>
<p>Use Quick Add or ask ARYA in chat!</p>

// After:
<p>{t('reminders_empty')}</p>
<p>{t('reminders_empty_sub')}</p>
```

**Day 4 — Add translations:**
For each key, add translations in all 25 language sections. Use GPT-4o to translate — it handles Indian scripts well. Human review for Malayalam and Hindi (most common users).

**Day 5 — Test:**
Switch to Malayalam. Go through every screen. Screenshot anything still in English. Fix.
